# 여유로운 출근길

1~8호선의 시간대별 혼잡도와 4호선의 칸별 혼잡도를 비교하는 Streamlit 대시보드입니다.

## GitHub에 업로드하고 배포하기

1. 배포 ZIP을 압축 해제합니다.
2. GitHub에서 새 저장소를 만들고 Public으로 설정합니다.
3. Add file → Upload files에서 압축을 푼 폴더 안의 파일과 data 폴더, .streamlit 폴더를 올린 뒤 Commit changes를 누릅니다. ZIP 자체를 올리지 말고 내용물을 올려야 합니다.
4. 저장소 첫 화면에 app.py와 requirements.txt, data 폴더가 보이는지 확인합니다. .streamlit 폴더가 누락되어도 기본 테마로 실행됩니다.
5. https://share.streamlit.io 에서 GitHub 계정으로 로그인합니다.
6. Create app에서 저장소와 main 브랜치를 선택하고 Main file path에 app.py를 입력합니다. 상위 폴더째 올렸다면 실제 경로인 subway_dashboard/app.py를 지정합니다.
7. Advanced settings에서 Python 3.12를 선택하고 Deploy를 누릅니다.
8. 공개 URL에서 두 분석 화면, 필터, 다운로드, 재생 버튼을 확인합니다.

앱 구동에 API 키와 별도 데이터 업로드가 필요하지 않습니다. 제공된 data 폴더에 실행용 자료가 들어 있습니다.

## 포함 파일

- app.py — 화면, 필터, 차트, 칸별 시간 재생
- requirements.txt — 검증한 라이브러리 버전
- .streamlit/config.toml — 흰색·청록색 테마
- data/network.csv.gz — 1~8호선 혼잡도 전체 자료를 긴 형식으로 변환
- data/cars_daily.parquet — 4호선 날짜·구간·30분·호차별 관측 합계와 관측수
- data/metadata.json — 원본 이름, 기간, 행 수와 전처리 기록
- prepare_data.py — 사용자 원본에서 실행용 자료를 다시 만드는 코드

## 로컬 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 원본으로 데이터 재생성

원본 두 파일을 raw 폴더에 넣고 아래 명령을 실행합니다. raw 폴더에는 1~8호선 CSV 한 개와 4호선 바깥쪽 ZIP 한 개를 둡니다.

```bash
python prepare_data.py raw
```

배포 패키지에는 가벼운 실행용 집계 자료를 넣었습니다. 원본은 사용자가 받은 파일을 보관하면 됩니다. 재생성 과정에서는 4호선 ZIP 안의 모든 분할 ZIP과 CSV를 읽습니다.

## 질문과 화면

탑승 시간을 조정하면 혼잡도가 얼마나 달라지며, 4호선에서는 칸 선택으로 얼마나 더 줄일 수 있을까요?

1~8호선 화면에는 시간대별 선그래프, 선택 시간 전후 비교 막대그래프, 같은 시각의 역별 순위, 역·시간대 히트맵이 있습니다. 날짜 대신 원본의 평일·토요일·일요일 유형을 선택합니다.

4호선 화면에는 관측 날짜 범위, 평일·휴일, 현재역→다음역 구간, 탑승 시간 범위와 최소 관측일 필터가 있습니다. 칸별 그림, 자동 재생, 막대그래프, 호차·시간대 히트맵과 호차별 선그래프를 제공합니다. 기준 호차를 선택하면 같은 시각의 칸 변경과 30분 앞당기기의 평균 혼잡도 차이를 확인할 수 있습니다.

## 집계와 해석

- 1~8호선은 2026년 9월 기준 제공된 30분 평균 혼잡도를 그대로 사용합니다. 같은 이름에 다른 역코드가 있으면 각 코드로 구분합니다.
- 원본 0%는 운행·관측 여부를 확인하기 어려워 기본 차트와 추천에서 제외합니다. 사이드바 체크박스로 원본 값을 포함할 수 있습니다. 양수 값의 결측 대체나 보간은 하지 않습니다.
- 4호선은 2026년 6월 1일~7월 31일 신조 전동차 자료입니다. 원본 요일구분인 평일·휴일을 유지합니다. 현재역과 다음역의 조합으로 방향을 구별합니다. 원본의 당고개 등 역명도 유지합니다.
- 30분 구간 안의 날짜별 평균을 구한 뒤, 선택된 날짜 평균들을 동일 가중치로 평균 냅니다. 원본 관측수와 날짜 수를 보존합니다. 4호선의 유효한 0%는 실제 관측값으로 포함합니다.
- 추천 조건의 최소 관측일은 기본 3일입니다. 기간·구간에 따라 관측 날짜가 달라질 수 있어 조건 간 차이를 인과효과로 해석하지 않습니다.
- 혼잡도는 정원 대비 비율이며 100%를 넘을 수 있습니다. 감소 폭은 퍼센트포인트(%p)입니다. 칸 그림은 원본 호차 번호를 나타냅니다.
- 자동 재생은 과거 평균 패턴을 시간 순서대로 보여줍니다. 30분 구간의 값이 한 단계씩 바뀌며 현재 열차의 상태와 추천 결과는 차이가 날 수 있습니다.
- 두 데이터는 조사 시기와 집계 방식이 다릅니다. 각 화면 안에서 비교합니다. 4호선 일부 차량의 결과를 전체 열차로 일반화할 때 대표성에 한계가 있습니다.
- 집에서 출발하는 시간과 도착 마감 시각을 계산하려면 이동시간·시간표 데이터가 추가로 필요합니다. 현재 화면의 시간은 선택한 역의 탑승 시간대입니다.
